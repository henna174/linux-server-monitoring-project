# Linux Server Administration, Monitoring & Automated Troubleshooting

## Project Overview
This project demonstrates Linux server administration
using AlmaLinux 10.2 and Nginx.

## Technologies
- AlmaLinux 10.2
- Nginx
- Bash Scripting
- systemd
- firewalld
- SELinux
- Cron
- Git and GitHub

## Features
- Nginx web hosting
- User and permission management
- SSH security
- Firewall configuration
- CPU, RAM and disk monitoring
- Log analysis
- Automated service recovery
- Automated website backups
- Cron scheduling

## Project Objective
To build and manage a secure Linux web server
with monitoring and automated troubleshooting.
